# JobFlow

JobFlow 是一款在本地运行的求职管理工具，将公司、岗位、简历版本和投递进度集中在一个工作台中，适用于实习、校招和社招。

## 功能

- **公司与岗位**：整理感兴趣的机会，保存招聘链接和联系人信息。
- **简历版本**：管理不同版本的简历，将实际提交的版本关联到每次投递。
- **进度跟踪**：记录申请阶段、面试安排与 Offer，查看完整的求职时间线。
- **今日待办**：集中查看需要处理的事项、即将到来的安排和等待回复的申请。
- **笔记与附件**：保存岗位分析、面试记录及相关文件。
- **本地保存**：数据保存在自己的电脑上，可导出 ZIP 备份。

## 开始使用

### Windows 便携包

1. 将完整便携包解压到一个固定文件夹。
2. 首次使用时运行 `01_Check.cmd`，确认显示 `CHECK PASSED`。
3. 双击 `02_Start.cmd`，在浏览器中打开启动窗口显示的本地地址。
4. 使用期间保持启动窗口打开；结束时在该窗口按 `Ctrl+C`。

便携包已包含运行环境，无需另外安装 Python、Node.js 或 WSL。通过 Git 克隆的源码不包含运行环境，安装方式见 [运行与开发](docs/DEVELOPMENT.md)。

### 添加第一条申请

点击「新建申请」，填写公司、岗位和招聘链接。尚未投递的机会可以先设为「感兴趣」，投递日期留空。

准备好简历后，在「文档」中保存相应版本。实际投递后更新日期和阶段，并关联提交的简历。后续收到回复或面试邀请时，继续记录进展和下一步事项。

## 备份

求职记录和上传文件保存在程序目录的 `data/` 中。

先停止正在运行的程序，再双击 `03_Backup.cmd`。生成的 ZIP 文件保存在 `backups/` 中，可复制到其他磁盘保存。
